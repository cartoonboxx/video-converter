# Video to MP4 (Electron + TypeScript)

Простое локальное desktop-приложение для пакетной конвертации `.mov` и `.avi` в `.mp4`.

## Что умеет

- Добавлять любое количество `.mov` / `.avi` файлов кнопкой или drag-and-drop.
- Конвертировать их параллельно в MP4.
- Опция «Сжимать видео» по умолчанию выключена. Без неё видео и все аудиодорожки переносятся в MP4 без перекодирования и потери качества. Если исходные кодеки несовместимы с MP4, приложение предложит включить сжатие; автоматического перекодирования нет.
- При включённом сжатии — видео: H.264 (`libx264`), CRF 22 и preset `slow` для баланса качества и размера, совместимый pixel format `yuv420p`. Исходное разрешение и частота кадров сохраняются.
- При включённом сжатии — аудио: первая аудиодорожка, AAC 128 кбит/с.
- В режиме сжатия битрейт подстраивается под сложность сцен: простые сцены занимают меньше места, детальные получают больше данных. Максимальный видеобитрейт — 7500 кбит/с с буфером 15000 кбит для кратковременных пиков. Для длинных видео ориентир сверху — около 60 МБ на минуту вместе со звуком; короткие ролики могут отличаться из-за буфера и накладных расходов MP4. Жёсткого ограничения 40 МБ на минуту больше нет.
- В режиме сжатия кодирование выполняется в один проход; preset `slow` повышает эффективность сжатия, но требует больше вычислений, чем `medium`.
- Показывать прогресс каждого файла.
- Не перезаписывать готовые MP4: при совпадении имени добавляется `(1)`, `(2)` и т.д.
- Отменять текущую конвертацию.
- Работает полностью локально, без загрузки видео в интернет.

## Быстрая сборка для Windows

1. Установите **Node.js LTS**.
2. Распакуйте этот проект в обычную папку.
3. Дважды кликните `BUILD_WINDOWS.bat`.
4. После сборки установщик появится в папке `release`.

Для запуска без создания установщика используйте `RUN_DEV.bat`.

## Команды вручную

```bash
npm install
npm start
```

Собрать Windows installer:

```bash
npm run dist:win
```

Собрать portable `.exe`:

```bash
npm run dist:portable
```

> Важно: Windows-сборку лучше выполнять на Windows, чтобы `ffmpeg-static` установил правильный FFmpeg-бинарник для Windows.

## Сборка для macOS

На macOS выполните `npm run dist:mac`. В `release` появятся DMG для Intel (x64) и Apple Silicon (arm64), каждый с FFmpeg соответствующей архитектуры.

Сборки подписываются ad-hoc, без нотариализации Apple. При первом запуске может потребоваться разрешить открытие в настройках конфиденциальности и безопасности macOS.
