# Video to MP4 (Electron + TypeScript)

Простое локальное desktop-приложение для пакетной конвертации `.mov` и `.avi` в `.mp4`.

## Что умеет

- Добавлять любое количество `.mov` / `.avi` файлов кнопкой или drag-and-drop.
- Конвертировать их по очереди в MP4.
- Видео: H.264 (`libx264`), качество CRF 20, совместимый pixel format `yuv420p`.
- Аудио: AAC 192 kbps.
- Показывать прогресс каждого файла.
- Не перезаписывать готовые MP4: при совпадении имени добавляется `(1)`, `(2)` и т.д.
- Отменять текущую конвертацию.
- Работает полностью локально, без загрузки видео в интернет.

## Быстрая сборка для Windows

1. Установите **Node.js LTS**.
2. Распакуйте этот проект в обычную папку.
3. Дважды кликните `BUILD_WINDOWS.bat`.
4. После сборки установщик появится в папке `release`.

Для запуска без создания установщика используйте `RUN_DEV.bat`.

## Команды вручную

```bash
npm install
npm start
```

Собрать Windows installer:

```bash
npm run dist:win
```

Собрать portable `.exe`:

```bash
npm run dist:portable
```

> Важно: Windows-сборку лучше выполнять на Windows, чтобы `ffmpeg-static` установил правильный FFmpeg-бинарник для Windows.
